# Tropass Connect

Tropass Connect — интеграция агентских сред с платформой Tropass.

## Language

**Tropass Connect**:
Интеграция, через которую OpenCode получает доступ к моделям, инструментам и инструкциям Tropass.
_Avoid_: MCP Installer, Agent Kit

**Агентская среда**:
Приложение, в котором агент использует подключённые возможности Tropass.
_Avoid_: MCP-клиент

**Диагностика Tropass Connect**:
Проверка состояния подключения Tropass в агентской среде, которая выявляет проблемы и подсказывает, как их устранить.

**Лимиты LLM-модели**:
Максимальный размер контекста и ответа конкретной LLM-модели. Не относятся к недельному расходу токенов пользователя.
