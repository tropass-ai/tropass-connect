# Tropass Connect

[`@tropass/connect`](https://www.npmjs.com/package/@tropass/connect) за одну команду подключает агентскую среду [OpenCode](https://opencode.ai/) к платформе [Tropass](https://тропасс.рф/). После установки агент вызывает ML-модели через MCP, использует LLM Tropass и разбирает структурированные ответы моделей.

## Быстрый старт

Для установки нужны:

- [Node.js](https://nodejs.org/en/download) 22 или новее;
- [OpenCode](https://opencode.ai/docs/#install) 1.17.16 или новее;
- [uv](https://docs.astral.sh/uv/getting-started/installation/) с доступной командой `uvx`;
- [API-токен Tropass](https://ядро.тропасс.рф/api-keys).

Запустите установщик:

```bash
npx -y @tropass/connect@latest
```

Установщик попросит выбрать область установки и ввести API-токен. Затем перезапустите OpenCode. По умолчанию выбрана глобальная настройка для текущего пользователя.

## Возможности

- **ML-модели через MCP.** Агент выбирает подходящую модель Tropass, проверяет аргументы и дожидается результата.
- **LLM-провайдер Tropass.** Список доступных моделей загружается из LLM-шлюза при запуске OpenCode. Моделью по умолчанию становится `GLM-5.2`, если она доступна, иначе первая модель из списка.
- **Инструкции для агента.** Установщик добавляет skills для вызова моделей и обработки текстов, графиков, медиа и вложений в их ответах.
- **Статистика токенов.** Команда `/usage` показывает недельный расход, остаток и время обновления лимита без запроса к LLM.
- **Диагностика.** Команда `/doctor` проверяет версию OpenCode, настройки и авторизацию, MCP- и LLM-шлюзы, каталог моделей и их лимиты, `uvx` и режим вызова. Результат — один экран `OK` / `WARNING` / `ERROR` с рекомендациями, без обращения к LLM и вывода API-токена. Синхронный режим v1 без `uvx` и неполные лимиты моделей отмечаются как `WARNING`.
- **Обновления.** При запуске OpenCode плагин предлагает обновиться сразу или напоминает об этом через 24 часа.
- **Повторная установка.** Обновляет интеграцию Tropass и не трогает остальные настройки OpenCode.

Адреса MCP- и LLM-шлюзов заполняются автоматически. При необходимости их можно переопределить флагами `--url` / `--llm-url` (или переменными окружения `TROPASS_MCP_URL` / `TROPASS_LLM_URL`).

## Установка

Глобальная установка делает Tropass доступным во всех проектах текущего пользователя:

```bash
npx -y @tropass/connect@latest opencode --global
```

Проектная установка настраивает только текущий рабочий каталог:

```bash
npx -y @tropass/connect@latest opencode --local
```

> При проектной установке `opencode.json` и `.opencode/tropass.mjs` содержат API-токен. Не добавляйте эти файлы в публичный репозиторий.

### Асинхронные задачи моделей

Для работы с моделями нужны [uv](https://docs.astral.sh/uv/getting-started/installation/) и команда `uvx`. Длительные задачи запускаются асинхронно: агент отправляет задачу и ждёт результат отдельным инструментом.

После установки `uv` откройте новый терминал и проверьте, что `uvx` доступен:

```bash
uvx --version
```

Полный список параметров:

```bash
npx -y @tropass/connect@latest --help
```
